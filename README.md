# 軍隊戦略アクションRPG 🎮⚔️

## ゲーム概要
100体のユニットを小隊単位で管理し、4つの職業（戦士、弓兵、魔法使い、僧侶）を組み合わせた大規模戦闘を楽しむ戦略アクションRPGです。

## 🎯 ゲームの特徴

### ユニット職業システム
- **戦士** 🛡️: 高い防御力と挑発スキル、前線で敵の攻撃を引き受ける
- **弓兵** 🏹: 長距離攻撃、高い攻撃力だが低い防御力
- **魔法使い** 🔮: 範囲魔法攻撃、高いダメージだが低い体力
- **僧侶** ⛪: 味方の回復、サポート魔法

### 小隊編成システム
- 最大10体のユニットで小隊を編成
- バランス編成：各職業を均等に配置
- 5種類のフォーメーション：横列、縦列、箱型、くさび型、円形

### 戦闘システム
- リアルタイム戦闘
- AI自動戦闘
- 戦術指令（突撃、後退、スキル使用）

## 🎮 操作方法

### 基本操作
- **スペースキー**: 戦闘開始/終了
- **Bキー**: 戦闘モード切り替え

### フォーメーション変更
- **1キー**: 横列フォーメーション
- **2キー**: 箱型フォーメーション  
- **3キー**: くさび型フォーメーション
- **4キー**: 円形フォーメーション

### 戦術指令
- **Tキー**: 全軍突撃命令
- **Yキー**: 全軍後退命令
- **Qキー**: 全小隊スキル使用

### 情報表示
- **Cキー**: 戦闘統計表示
- **Sキー**: 小隊状況確認
- **Uキー**: 戦闘結果表示
- **Gキー**: 全ユニット集合
- **Vキー**: ユニット色分け表示
- **Rキー**: 小隊再編成

## 🛠️ Unity設定手順

### 1. プロジェクト作成
```
1. Unity Hub で新しい3Dプロジェクトを作成
2. プロジェクト名: "MilitaryRPG"
```

### 2. スクリプト配置
```
Assets/
└── Scripts/
    ├── Core/
    │   ├── GameManager.cs
    │   ├── UnitManager.cs
    │   ├── SquadManager.cs
    │   └── CombatManager.cs
    ├── Units/
    │   ├── UnitClass.cs
    │   └── Unit.cs
    └── Squads/
        └── Squad.cs
```

### 3. シーン設定
1. **NavMesh設定**
   - Window > AI > Navigation
   - 地形オブジェクトを選択
   - Navigation Static にチェック
   - Bake ボタンをクリック

2. **GameManager設定**
   - 空のGameObjectを作成し、"GameManager"と命名
   - GameManager, UnitManager, SquadManager, CombatManagerスクリプトをアタッチ

3. **地形作成**
   - Terrainを作成するか、大きなPlaneオブジェクトを地面として配置
   - Navigation Staticに設定

### 4. カメラ設定
- カメラを高い位置（Y=50程度）に配置
- 下向きに角度調整（X=60度程度）
- 戦場全体が見渡せるように設定

## 🎲 ゲームの流れ

### 1. 初期化フェーズ
- 100体のユニットを自動生成
- 職業をランダムに割り当て
- 色分けで職業を視覚化

### 2. 編成フェーズ  
- ユニットを小隊に自動編成
- フォーメーションを配置
- 戦闘準備完了

### 3. 戦闘フェーズ
- スペースキーで戦闘開始
- 敵軍が自動生成される
- AI同士の自動戦闘開始

### 4. 戦術フェーズ
- リアルタイムで戦術指令を発行
- フォーメーション変更
- スキル使用指示

### 5. 結果フェーズ
- 戦闘終了後に結果表示
- 生存者数と戦死者数を集計
- 小隊の自動再編成

## 🔧 カスタマイズ可能な設定

### UnitManager設定
- `warriorRatio`: 戦士の割合 (デフォルト: 30%)
- `archerRatio`: 弓兵の割合 (デフォルト: 30%)
- `mageRatio`: 魔法使いの割合 (デフォルト: 20%)
- `priestRatio`: 僧侶の割合 (デフォルト: 20%)

### SquadManager設定
- `maxSquadSize`: 小隊の最大人数 (デフォルト: 10)
- `balancedSquads`: バランス編成の有効/無効
- `squadSpacing`: 小隊間の距離

### CombatManager設定
- `battleRadius`: 戦闘開始距離
- `battleUpdateInterval`: 戦闘更新間隔
- `autoBattleMode`: 自動戦闘モード

## 📝 トラブルシューティング

### よくある問題
1. **ユニットが動かない**
   - NavMeshが正しくBakeされているか確認
   - NavMeshAgentコンポーネントが正しく設定されているか確認

2. **戦闘が始まらない**
   - CombatManagerが正しくアタッチされているか確認
   - ユニットが正しく生成されているか確認

3. **ユニットが表示されない**
   - Rendererコンポーネントが正しく設定されているか確認
   - カメラの位置と向きを確認

### パフォーマンス最適化
- ユニット数を減らす（50体など）
- 戦闘更新間隔を長くする
- 不要なオブジェクトのCulling設定
